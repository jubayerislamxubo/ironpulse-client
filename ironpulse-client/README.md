# 🏋️‍♂️ IronPulse - Client Side

Welcome to **IronPulse**, a modern fitness and workout tracking web application. This is the front-end client repository built with React, Vite, and Tailwind CSS.

## 🚀 Live Demo
- **Live Website:** https://b13-a10-frontend.vercel.app/

## ✨ Key Features
- **User Authentication:** Login and Registration system with Email/Password and Social Logins.
- **Interactive Dashboard:** Track daily fitness routines, workout sessions, and stats.
- **Dynamic Classes & Trainers:** Browse available gym classes and top trainers.
- **Responsive Design:** Fully optimized for Mobile, Tablet, and Desktop screens.
- **Dark/Light Mode Support:** Clean and modern UI for better user experience.

## 🛠️ Technologies Used
- **Frontend Framework:** React (Vite)
- **Styling:** Tailwind CSS, DaisyUI
- **Routing:** React Router DOM
- **Icons & Animations:** Lucide React / React Icons, Framer Motion
- **Hosting:** Vercel
